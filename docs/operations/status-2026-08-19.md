# Where great-wiki stands — 2026-08-19

Written at the owner's request, because decisions were getting buried inside long progress
messages. This is the accounting: what was built, what is live, what is open, and what the
original roadmap still has waiting.

## The state in one paragraph

`wiki.ohje.ooguy.com` is live on the public internet, running `038016b`, holding 35 pages of
the owner's ADHD/microbiota reference with 34 revisions of history, 29 link edges and inline
formatting throughout. It has identity and access control, collaborative editing, sortable
tables, markdown import and export, backlinks and a graph. Milestones M0-M2 are complete;
M3 is about two-thirds done; the Joplin-replacement work has finished its first two of five
pieces.

### Known defects, none blocking

| Item | Severity | Note |
|---|---|---|
| 17 `behaviour.mjs` checks fail | Important | The harness had never been run end to end. Groups C (tables) and E (editor) time out; D5 asserts a stale hardcoded count. They were written, committed and believed. |
| Graph labels overlap | Important | ~1/3 of labels collide at 35 nodes, in 2-3 dense clusters. Needs a look before choosing a fix. |
| `render()` reports no problem for some inexpressible markdown | Important | Pre-existing, 80% smaller than before; the export guard refuses rather than corrupts |
| One refusable page fails the whole export | Important | Page content is writer-controlled, so one bad page means no backup at all |
| No Content-Security-Policy | Important | On a public site that renders authored content |
| Duplicate same-kind marks on a leaf dropped | Minor | Degenerate input only |
| `//evil.example` allowed as a link | Minor | Phishing legibility, not XSS |
| `plain_text` mirrors differ on U+0085 / U+FEFF | Minor | Rust and TypeScript whitespace rules disagree |
| Unbounded `links` read, no limit | Minor | Irrelevant at 35 pages |

## Things worth remembering

- **The API tokens and MCP server** the owner chose for AI-agent access are not built. They
  need M14 pulled forward, and the MCP server sits on top of that API.
- **A graph is a disclosure surface.** Every node, edge and backlink filters through the one
  permission-checked accessor, per document rather than per subtree. This is mutation-tested.
- **Nothing has been verified in a browser by a human.** Group F browser checks exist for the
  graph; the owner has not looked at it, and only they can sign in to see the real one.
