> For agentic workers: use superpowers:subagent-driven-development. Spec:
> [datasets-views-design](../specs/2026-10-10-datasets-views-design.md). ADR draft 0029.
> Every task: failing test first → minimal code → test green → `just ci`. ≤ 3 files + tests,
> ≤ 200 lines. Stage explicit paths. Gates: `just ci` always; `just mutate` where marked
> (gw-store / gw-auth); `just behaviour` groups where marked (new group letters append after E).

**Baseline:** origin/main f6c9a77. Next migration 0020. Next ADR 0029.
**Phases:** M8a table + core fields (ships alone) → M8b relational/computed fields → M8c board

## M8a — dataset page, core field types, table view

**A1 Field key + kinds (gw-core, `dataset/key.rs`, `dataset/kind.rs`, `dataset/mod.rs`).**
Test first: `FieldKey::parse` accepts `a`, `a_1`; refuses `""`, `1a`, `A`, `a-b`, `a b`, `a"`,
`a'; --`, 49 chars, reserved names, and every ASCII punctuation/control char one at a time
(property test: any char outside `[a-z0-9_]` anywhere → refused). Then `FieldKind` enum (12 kinds, serde snake_case).
Gate: `just ci`.

**A2 Value validation (gw-core, `dataset/value.rs`).** Test first, one per kind: number
rejects NaN/Inf; url rejects `javascript:`/`data:`; date formats; select rejects an unknown
option id; multi_select dedupes; unknown row key refused; row > 64 KiB refused. Implement
`validate_value` + `validate_row` for text number bool date select multi_select tags url
(person/file/relation get typed stubs returning `NeedsStore`). Gate: `just ci`.

**A3 Migration 0020 (gw-store `migrations/0020_datasets.sql`, `datasets.rs` skeleton, test).**
Test first: after migrate, `dataset_field`, `dataset_row` exist; `UNIQUE(doc_id,key)`;
`CHECK` kind IN list; deleting the document cascades; content type `dataset` accepted by
`documents` (inspect the column; add to CHECK if present). Gate: `just ci`.

**A4 Dataset page creation (gw-store `datasets.rs`, gw-api route, test).** Test first:
creating under a parent requires write on it, refuses unreadable parent as "no page at …"
(ADR 0028 same gate); result is a page of type `dataset` with empty schema. Gate: `just ci`.

**A5 Schema CRUD (gw-store `datasets.rs`, gw-api route, test).** Test first: add/rename-label/
reorder/delete field; kind and key immutable; >100 fields refused; delete field strips key from
all rows in one transaction; requires write. Gate: `just ci`, `just mutate` (add:
`datasets.rs` — "schema write without write check" killed).

**A6 Row CRUD + version (gw-store `datasets.rs`, gw-api route, test).** Test first: create
validated row; stale `version` → conflict returning current row; unknown key refused; >50 000
rows refused; delete; event `dataset.row.*` emitted (ADR 0025) and re-authorised at delivery.
Gate: `just ci`.

**A7 Access seam (gw-store `datasets.rs` `readable_dataset`, gw-auth test).** Test first: an
unreadable dataset answers identical bytes to a nonexistent one (ADR 0022); guest, other-group,
admin, view-as. All of list/count/row-get route through it. Gate: `just ci`; **`just mutate`
entries (gw-store/gw-auth):** (1) `readable_dataset` always true → killed; (2) row list skips
the check → killed; (3) count computed before filtering → killed.

**A8 Query layer (gw-store `datasets/query.rs`, test).** Test first: filter eq/contains/
is_empty/in, typed sort number vs text ("10" > "9" for numbers), keyset cursor stable under
insert; a hostile key (`a') OR 1=1 --`) is refused at `FieldKey::parse` before SQL and a unit
test asserts the builder has no `&str` constructor path. Gate: `just ci`, `just mutate`
("key interpolated" variant: replace bound param with `format!` → killed).

**A9 Table view API + saved views (gw-store `0021_dataset_views.sql`, `views.rs`, gw-api route).**
Test first: view create/list/update/delete requires write; list for a reader returns views
minus fields hidden from them; a view config naming a nonexistent field is refused. Gate:
`just ci`.

**A10 Table UI (web `lib/datasets/TableView.svelte`, `routes` data load, test).** Test first
(vitest): renders typed cells, sort click, filter chip, cursor "load more", empty state, error
cell. Text rendered as text (no HTML sink; `check-html-sinks.sh` stays green). Gate: `just ci`,
**`just behaviour` Group F "dataset table"**: open a fixture dataset as editor, add row, sort,
filter, reload persists; as guest 404-equivalent. Add fixture dataset to `behaviour-fixture`.

**A11 Row editing UI (web `RowEditor.svelte`, `cells/*.svelte` ≤3 files per kind group, test).**
Test first: each cell editor emits the validated shape; 409 shows current row and keeps draft.
Split into A11a (text/number/bool/date/url) and A11b (select/multi_select/tags) if > 200 lines.
Gate: `just ci`, behaviour Group F additions. **Release point: M8a ships here.**

## M8b — person, file, relation, rollup, formula

**B1 Formula evaluator (gw-core `formula/{lex,parse,eval}.rs`, tests).** Test first: precedence,
`if`, `coalesce`, divide-by-zero → `#ERR`, node budget 256, step budget 10 000, depth 32 each
refuse a crafted input, `today()` uses injected clock, unknown field ref refused at parse;
a seeded-random malformed-input loop (1 000 strings) never panics and always yields `#ERR`.
Split B1a lexer+parser, B1b evaluator if > 200 lines. Gate: `just ci`.

**B2 Formula in schema (gw-core `formula/deps.rs`, gw-store `datasets.rs`, test).** Test first:
cycle between two formulas refused at schema save; formula over a rollup allowed; evaluation at
read, never stored. Gate: `just ci`.

**B3 person + file fields (gw-store `datasets.rs`, `value.rs`, test).** Test first: person who
cannot read the page refused (ADR 0009 cl. 2); clear/unassign always allowed with write; file
must be an attachment of the dataset page; trashed attachment renders as missing, not error.
Gate: `just ci`, `just mutate` (cl. 2 check removed → killed).

**B4 Relation (gw-store `0022_dataset_relations.sql`, `datasets/relation.rs`, test).** Test
first: write needs read on source **and** target dataset; target row must belong to target;
unreadable target → field omitted from schema+row for that caller, write refused with the
uniform message; deleting a target row removes edges; reverse lookup uses the index. Gate:
`just ci`, **`just mutate`:** (1) target read check removed → killed; (2) omission replaced by
empty array (leaks existence) → killed; (3) cross-target row accepted → killed.

**B5 Rollup (gw-store `datasets/rollup.rs`, test).** Test first: count/sum/min/max/avg/list over
visible rows only; a hidden target row changes no number (assert equal output with and without
it); empty-because-hidden equals absent. Gate: `just ci`, `just mutate` (aggregate before
filter → killed).

**B5b Field visibility in queries (gw-store `datasets/query.rs`, test).** Test first: a filter,
sort or group_by naming a field omitted for the caller (hidden relation, or a rollup/formula
whose dependency chain reaches one) is refused as an unknown key; such computed fields are
themselves omitted from schema and rows. Gate: `just ci`, `just mutate` (visibility check
removed → killed).

**B6 Computed fields in query (gw-store `datasets/query.rs`, test).** Test first: filter/sort on
formula and rollup happen after evaluation on the page window with a documented bound (≤ row
cap); excluded from `group_by`. Gate: `just ci`.

**B7 Relational UI (web `cells/RelationCell.svelte`, `cells/ComputedCell.svelte`, test).** Test
first: picker lists only rows from the readable target; `#ERR` cell shows reason as text. Gate:
`just ci`, behaviour Group F: relation round trip, guest sees omitted column.
