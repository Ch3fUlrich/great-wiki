# Start hier

Dies ist der aktuelle Stand von **great-wiki**. Alles auf dieser Seite läuft
wirklich — es ist kein Entwurf und kein Bild.

## Was du jetzt prüfen kannst

Geh die Seiten unter *Rundgang* durch. Jede zeigt eine Fähigkeit, die schon
funktioniert, und nennt am Ende, was noch fehlt.

1. **Rundgang → Was schon geht** — Überschriften, Listen, Zitate, Code
2. **Rundgang → Deutsch und Umlaute** — wie aus `Größe und Maß` eine saubere Adresse wird
3. **Rundgang → Tabellen** — was heute passiert und warum
4. **Rundgang → Wer was sieht** — die Berechtigungsgrenze, sichtbar gemacht

## Was ausdrücklich noch nicht geht

Ehrlichkeit ist hier nützlicher als ein guter Eindruck:

- **Bearbeiten im Browser.** Diese Seiten kommen aus Markdown-Dateien. Der Editor
  ist der nächste große Abschnitt.
- **Suche.** Noch nicht gebaut.
- **Bilder, Videos, Diagramme, Formeln.** Noch nicht gebaut.
- **Anmeldung in der Anwendung selbst.** Du bist über Authelia hereingekommen,
  nicht über great-wiki. Deshalb siehst du gerade *alles*.
