# Verweisbeispiel

Eine kleine, öffentliche Seite mit genau einer Unterseite, die auf sie zurückverweist —
damit [/graph](/graph) (D-4) auch in einem frisch geklonten Repository ohne
`content-darm` etwas Echtes zu zeichnen hat: ein Knoten, ein Pfeil, kein erfundenes
Beispiel.
