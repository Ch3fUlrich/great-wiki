# Verweisbeispiel

Eine kleine, öffentliche Seite mit genau einer Unterseite, die auf sie zurückverweist —
damit [/graph](/graph) (D-4) auch in einem frisch geklonten Repository ohne
`content-darm` etwas Echtes zu zeichnen hat: ein Knoten, ein Pfeil, kein erfundenes
Beispiel.

## Was ein Verweis ist {#0199c0de-0000-7000-8000-00000000000a}

Ein Verweis zeigt auf die **Identität** einer Seite, nicht auf ihre Adresse. Wird die Seite
später umbenannt oder verschoben, zeigt er immer noch dorthin.

Dieser Abschnitt trägt eine feste Ankerkennung — die geschweifte Klammer hinter der
Überschrift — und genau die macht ihn einbettbar: die Überschrift darf umformuliert werden,
ohne dass eine Einbettung ins Leere läuft.
